# Proiect Python - Recunoașterea unor elemente într-o imagine data 

## Descriere proiect:
- Acest proiect are ca scop recunoașterea și detectarea unor elemente specifice într-o imagine dată, folosind tehnici de procesare a imaginilor și metode de învățare automată (machine learning).  
- Proiectul este dezvoltat în Python, utilizând librării precum OpenCV și un model pre-antrenat YOLOv8 pentru detecția obiectelor.

## Funcționalități
- Detectarea elementelor vizuale specifice (ex: semne de circulație, obiecte, forme).
- Afișarea rezultatelor prin suprapunerea unor chenaruri (bounding boxes) pe imagine.
- Exportarea rezultatelor într-un folder dedicat.



## Tehnologii:
- Python
- OpenCV
- YOLOv8n (model pre-antrenat)
